# -Этот текстовый квест по мотивам игры в бункер. Вы попадаете в мир,где вся планета под угрозой.На Земле появляется вирус,который может убить все человечество, и только вы его можете спасти.Вы должны найти и спрятаться в бункере, в котором проведете 3 года.А помогает вам умерший брат, который работал в той самой лаборатории, где и обнаружили вирус.
